## 🎯 About the Project
In the competitive landscape of E-commerce, treating every customer with a one-size-fits-all approach is inefficient and costly. This project analyzes a complete transaction history to answer vital business questions:
* Who are our **most loyal and profitable customers** (Champions)?
* Which valuable customers are **at risk of churning**?
* How can we tailor our marketing campaigns to maximize Return on Investment (ROI)?

---

## 📊 What is the RFM Model?
The model segments customers based on three quantitative behavioral metrics:
1. **Recency (R):** How recently did the customer make a purchase? (Days since last transaction).
2. **Frequency (F):** How often do they buy? (Total number of transactions).
3. **Monetary (M):** How much money do they spend? (Total revenue generated by the customer).

Based on these values, customers are assigned scores (typically from 1 to 5) using quantiles and grouped into strategic business segments (e.g., *Champions, At Risk, Lost, New Customers*).

## 🛠️ Tech Stack & Libraries
This project is built entirely in **Python**, utilizing an industry-standard data analysis stack:
* **Pandas & NumPy:** Data wrangling, cleaning, transformation, and numerical computations.
* **Matplotlib & Seaborn:** Exploratory data analysis and visualization generation.
* **Jupyter Notebooks:** Interactive environment for hypothesis testing and data storytelling.

---

## ⚙️ Methodology & Pipeline
1. **Data Cleaning & Preprocessing:** Handled missing values, removed canceled orders and duplicate rows, and parsed datetime formats.
2. **RFM Metrics Calculation:** Aggregated transaction logs at the customer ID level relative to a reference snapshot date.
3. **Score Assignment:** Applied quintile ranking to score each customer from 1 to 5 across Recency, Frequency, and Monetary dimensions.
4. **Customer Segmentation:** Mapped combined RFM scores into intuitive marketing segments.
5. **Insights & Visualization:** Plotted segment distributions to understand customer lifecycle stages and formulate strategic growth recommendations.

---

## 📈 Key Insights & Results
* **Champions:** Comprise a significant portion of total revenue with frequent and recent checkouts. *Strategy: Reward loyalty with VIP perks and early access.*
* **At Risk Customers:** Previously high-spending customers who haven't purchased recently. *Strategy: Deploy re-engagement campaigns and personalized win-back offers.*

## 🚀 How to Run the Project Locally

Follow these instructions to clone and run the analysis on your machine:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/H-530/ecommerce-rfm-data-analysis.git
   cd ecommerce-rfm-data-analysis
   ```

2. **Create and activate a virtual environment (Recommended):**
   ```bash
   python -m venv venv
   # On Windows:
   venv\Scripts\activate
   # On macOS/Linux:
   source venv/bin/activate
   ```

3. **Install dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Launch Jupyter Notebooks:**
   ```bash
   jupyter notebook
   ```
   Open the `notebooks/` directory to explore the complete workflow.
